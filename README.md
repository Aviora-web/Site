# SYNTH//HUMAN

A responsive, minimalist cyborg-themed landing page built with HTML, CSS, and JavaScript. The centerpiece uses a procedural Three.js model, so no downloaded 3D model or build step is required.

## Run locally
Open `index.html` in a modern browser. The interactive 3D centerpiece loads Three.js from jsDelivr, so an internet connection is required for that enhancement. If the CDN/WebGL is unavailable, the page retains its content and layout.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `synth-human`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL appears in the Pages settings.

## Included interactions
- Responsive navigation menu on small screens
- Procedural interactive Three.js cyborg head
- Scroll-triggered content reveals
- Pointer-reactive specimen graphic
- Reduced-motion support
- CSS fallback if the 3D enhancement cannot load

## Notes
- The technologies shown on the page are fictional concepts for a visual design project, not claims about real products.
- Google Fonts and the Three.js module are loaded from third-party CDNs.
- Before submitting, test the published URL on your phone and record a 45–90 second walkthrough.
